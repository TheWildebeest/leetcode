## problem

you have to find the maximum profit you can make from a single buy-and-sell transaction given an array of daily stock prices.

## tl;dr

i found this pretty hard tbh.

the test cases give example prices arrays like this:

```ts
  const prices: number[] = [7,1,5,3,6,4];
```

obviously, you would buy on the second day (`day = 1`) for a price of `1`;

then you would sell on the fifth day (`day = 4`) for a profit of 6 - 1 = **5**

but how to make an algorithm that knows how to do this?

## i gave up and looked up the solution

i had got fixated on the peaks and troughs.

but calculating them is quite expensive.

and it turns out you don't need them at all.

you can just go through the prices array once and figure out the max profit:

- store the minimum price you have seen so far
- store the best profit you have achieved so far

so for each day, you only have to
  - **update the minimum price** if current day has a lower price; or,
  - **update max profit** if selling today gives better then

this is the code. it is so small and simple...


```ts
function maxProfit(prices: number[]): number {
    let minPrice = Number.POSITIVE_INFINITY;
    let i = 0;
    let maxProfit = 0;
    while (i < prices.length) {
        const currentPrice = prices[i];
        const currentProfit = currentPrice - minPrice;
        if (currentPrice < minPrice) {
            minPrice = currentPrice;
        } else if (currentProfit > maxProfit) {
            maxProfit = currentProfit;
        }
        i++;
    }
    return maxProfit
};
```

### my takeaways

visualizing the graphs was helpful. i should have let this prompt me to move away from thinking about peaks and troughs.

keeping track of only min price and not max price so far is not intuitive to me. but keeping track of max profit so far makes sense.

what the correct solution does is **compare profit you could make today with the best you could have made so far**, as you move forwards in time.

if today cant make you profit because the price is lower than its ever been — **buy today** and sell again only if you can make more profit.

it treats the future as unknown, and discovers it as it works through.

by contrast, if you tracked max price instead, you would have to go backwards in time.

this actually works too:

```ts
function maxProfit(prices: number[]): number {
    let maxPrice = -1;
    let i = prices.length - 1;
    let maxProfit = 0;
    while (i > -1) {
        const currentPrice = prices[i];
        const currentProfit = maxPrice - currentPrice;
        if (currentPrice > maxPrice) {
            maxPrice = currentPrice;
        } else if (currentProfit > maxProfit) {
            maxProfit = currentProfit;
        }
        i--;
    }
    return maxProfit;
};
```

this is basically tracking **the best price you could have sold at, if you had already bought at a lower price**.

you dont know if you could have bought it at a lower price because you are going backwards in time. and you don't have anything to sell yet.

as you move backwards, if buying today would let you keep more of the money you got by selling than any previous day — you have your new max profit number.

otherwise, if today is a higher price than youve ever seen before, you have a new max price number, though you may never be able to buy low enough to beat your existing margin.
